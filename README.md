# FOKUS - Simulador do Método Pomodoro

![image](https://github.com/user-attachments/assets/5ad47053-bb27-47a3-a691-d908b17c6025)

**FOKUS** é uma aplicação simples que simula o **método Pomodoro**, ajudando você a otimizar sua produtividade, organizando o tempo de estudo e pausas. O app permite alternar entre os ciclos de **foco**, **descanso curto** e **descanso longo**, e oferece a funcionalidade de um cronômetro com alerta sonoro para marcar o fim de cada sessão.

## Funcionalidades

- **Ciclo de Foco**: 25 minutos dedicados ao estudo sem interrupções.
- **Descanso Curto**: 5 minutos de pausa após um ciclo de foco.
- **Descanso Longo**: 15 minutos de pausa após alguns ciclos de foco.
- **Cronômetro**: Um timer regressivo para gerenciar o tempo de foco e as pausas.
- **Música de Foco**: Opção para ativar ou desativar uma música ambiente durante o ciclo de foco.
- **Alertas Sonoros**: Sons de início, pausa e término do ciclo, para manter o usuário informado.

## Tecnologias Utilizadas

- **HTML**: Estrutura da página.
- **CSS**: Estilização da interface.
- **JavaScript**: Lógica para controle do timer, alternância entre os ciclos e alertas sonoros.
- **Áudio**: Arquivos de áudio para os alertas e música de foco.

## Como Usar

1. **Clone o repositório**:
   - Clone este repositório com o comando:
     ```bash
     git clone https://github.com/SeuUsuario/fokus.git
     ```

2. **Abra o arquivo `index.html`** no seu navegador preferido.

3. **Use os botões** para alternar entre os ciclos de foco, descanso curto e descanso longo.

4. **Inicie o cronômetro** clicando no botão de play. O cronômetro começará a contagem regressiva, e você poderá pausar ou reiniciar o timer a qualquer momento.

5. **Ative ou desative a música** utilizando o controle de alternância no painel de opções.

## Como Funciona

1. O **FOKUS** possui três modos principais: **Foco**, **Descanso Curto** e **Descanso Longo**. Cada modo tem um tempo predefinido (25 minutos para foco, 5 minutos para descanso curto e 15 minutos para descanso longo).
2. O usuário pode clicar nos botões correspondentes para iniciar o ciclo desejado. O cronômetro começa a contar regressivamente, e um alerta sonoro é tocado ao final de cada ciclo.
3. O usuário também pode alternar a música de fundo (uma música relaxante) durante o ciclo de foco, ativando ou desativando a música no painel de opções.
